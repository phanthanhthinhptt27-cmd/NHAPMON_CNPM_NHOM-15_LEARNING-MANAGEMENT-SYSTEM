# NHAPMON_CNPM_NHOM-15_LEARNING-MANAGEMENT-SYSTEM

Dành cho sinh viên cần định hướng học tập và cố vấn học tập. Hệ thống Kết nối Mentor - Mentee là một nền tảng cầu nối tương tác, giúp sinh viên dễ dàng tìm kiếm cố vấn phù hợp, đặt lịch hẹn tư vấn và theo dõi lộ trình phát triển cá nhân. Khác với kênh liên lạc qua email thụ động, sản phẩm của chúng tôi cung cấp quy trình đặt lịch chủ động.

## 2. Phân hệ Quản lý Lớp học & Giảng dạy (LMS)
Phụ trách: **Trần Đức Duy**
